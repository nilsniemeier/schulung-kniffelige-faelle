# Kniffelige Fälle aus der Praxis – Schulung für Schornsteinfeger

Schulung (ca. 1 Stunde) mit neun praxisnahen Fällen: Situation, Diskussionsfragen und Lösungsansatz.

## Inhalt

| Datei | Beschreibung |
|---|---|
| `index.html` | Interaktive Lernseite (Folien, Lösung per Leertaste, Timer). Öffnet direkt im Browser. |
| `muendungshoehe.html` | Prüf-Tool zur Mündungshöhe nach § 19 Abs. 1 der 1. BImSchV (Standardfall, bis 200 kW). |
| `Kniffelige-Faelle.pptx` | PowerPoint-Präsentation mit Lösungen auf Klick und Seitenumblätter-Übergang. |

## Online ansehen (GitHub Pages)

Repository auf GitHub veröffentlichen und unter *Settings → Pages* den Branch `main` (Ordner `/ (root)`) auswählen.
Danach ist die Lernseite unter `https://<benutzername>.github.io/<repository>/` erreichbar,
das Prüf-Tool unter `.../muendungshoehe.html`.

## Hinweise

- Die Inhalte sind Diskussionsgrundlagen. Maßgeblich sind der aktuelle Rechtsstand, Landesrecht und die Vorgaben der zuständigen Behörde.
- Das Prüf-Tool ersetzt keine Berechnung nach VDI 3781 Blatt 4.
- Quelle für die Ableitbedingungen: [§ 19 der 1. BImSchV](https://www.gesetze-im-internet.de/bimschv_1_2010/__19.html).
